How email tracking works

A tracked email contains a tiny image, often 1×1 pixel, with an address that is unique to you. When Gmail shows the email, it downloads that image, and the sender's server records that you opened it, when, and how many times. Sales tools such as HubSpot, Mailtrack and Yesware, and newsletter services such as Mailchimp and SendGrid, do this by default.

Doesn't Gmail already block this?

Not fully. Gmail loads email images through its own proxy, which hides your IP address and rough location from the sender. But the proxy still downloads the image when you open the email, so the sender still learns that you opened it and when. Turning off images in Gmail's settings stops tracking, but it also hides every normal picture. Unseen blocks only the trackers. All the ways to block tracking in Gmail · In italiano.

How Unseen decides what to block

  1. It checks each image's original address against a list of 332 tracking patterns from about 195 companies, built from the open-source Simplify and Trocker lists.
  2. It also blocks hidden and 1×1 images, which have no purpose except tracking.
  3. Everything else loads as usual. A small note above the email names the tracker, with a Load images anyway button for that one email.

Questions

How is it different from Trocker, PixelBlock or Gblock?

Unseen asks for access to Gmail only, is open source and free for blocking. See an honest comparison, including where the others do better.

Can Unseen read my emails?

It looks only at the image addresses inside the emails you open. It never reads, stores or sends the text of your emails, your contacts or your address. The code is open source, so anyone can check.

Does it work with the Gmail app on my phone?

No. Unseen works in Gmail on the web, in a desktop browser.

Does it work in Outlook or Yahoo Mail?

Not yet. Gmail on the web only, for now.

Will senders know I blocked them?

They see the same thing as when someone reads email with images turned off: no open is recorded.
