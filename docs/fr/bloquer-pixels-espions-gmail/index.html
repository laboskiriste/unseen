Bloquer les pixels espions dans Gmail

Mis à jour le 5 novembre 2026. Écrit par le développeur d'Unseen, l'un des outils présentés ici. English version · Deutsche Version · Versione italiana

La plupart des newsletters et des e-mails commerciaux indiquent à l'expéditeur si vous les avez ouverts, quand et combien de fois. Ils utilisent un pixel espion (ou pixel de suivi) : une image minuscule, souvent de 1×1 pixel et invisible, dont l'adresse est unique pour vous. Quand Gmail affiche l'e-mail, il télécharge cette image, et le serveur de l'expéditeur enregistre l'ouverture. Les liens fonctionnent pareil : un lien suivi passe d'abord par le serveur de l'expéditeur, qui note le clic, puis vous redirige.

Ce que dit la CNIL

Dans sa recommandation sur les pixels de suivi dans les courriels, adoptée le 12 mars 2026 et publiée le 14 avril 2026, la CNIL considère ces pixels comme des traceurs. En règle générale, l'expéditeur doit donc obtenir votre consentement avant de mesurer l'ouverture de ses e-mails ou de vous profiler. Pour les adresses collectées avant le 14 avril, les entreprises avaient jusqu'au 14 juillet 2026 pour informer les destinataires et leur permettre de s'opposer.

  • Il existe des exceptions, par exemple pour la délivrabilité et certains e-mails transactionnels (confirmation de commande, mot de passe).
  • Vous devez pouvoir retirer votre consentement facilement.

En pratique, beaucoup d'e-mails contiendront encore des pixels : parce que vous avez accepté un jour, parce que l'expéditeur n'est pas en France, ou parce que personne n'a vérifié. Si vous ne voulez pas être suivi, le plus sûr est de les bloquer vous-même.

Gmail ne les bloque-t-il pas déjà ?

Pas entièrement. Gmail charge les images via son propre proxy, qui cache votre adresse IP et votre position approximative. Mais l'image est quand même téléchargée quand vous ouvrez l'e-mail, donc l'ouverture est quand même enregistrée.

Méthode 1 : désactiver les images dans Gmail (gratuit, intégré)

  1. Dans Gmail sur ordinateur, cliquez sur la roue dentée, puis sur Voir tous les paramètres.
  2. Dans l'onglet Général, à la ligne Images, choisissez Demander avant d'afficher des images externes.
  3. Descendez en bas et cliquez sur Enregistrer les modifications.

Dans l'application Gmail sur téléphone, la même option se trouve dans Paramètres, votre compte, Images.

L'inconvénient : toutes les images de tous les e-mails restent masquées jusqu'à ce que vous les affichiez, y compris les logos, les photos et les factures. Et dès que vous cliquez sur « Afficher les images », les pixels se chargent aussi. Cela ne bloque pas non plus le suivi des liens.

Méthode 2 : une extension qui ne bloque que les pixels

Une extension de navigateur laisse les images activées, mais reconnaît les pixels espions (par leur adresse, ou parce qu'ils sont cachés ou de 1×1) et ne bloque que ceux-là. Les images normales s'affichent comme d'habitude.

Unseen fait exactement cela, dans Gmail sur le web :

  • bloque plus de 330 traceurs connus et les pixels cachés ;
  • affiche au-dessus de chaque e-mail suivi le nom de l'entreprise qui a essayé de vous suivre, avec un bouton pour charger les images quand même ;
  • fonctionne uniquement sur Gmail et n'a accès à aucun autre site ;
  • pas de publicité, pas de statistiques, pas de compte ; open source (licence MIT) ;
  • le blocage est gratuit. La fonction Pro, facultative, ouvre les liens des e-mails à leur vraie adresse sans passer par le traceur de clics : 30 jours gratuits, puis 15 dollars une seule fois, sans abonnement.

Ajouter Unseen à Chrome, gratuit

Ce n'est pas la seule option : nous comparons honnêtement Unseen à Trocker, PixelBlock, Gblock et Ugly Email (en anglais). Trocker, par exemple, est gratuit et fonctionne aussi avec Outlook.com et Yahoo.

Avant d'installer une extension pour vos e-mails

Une extension qui fonctionne dans Gmail peut voir vos e-mails. Vérifiez donc trois choses sur sa page du Chrome Web Store :

  • Autorisations : elle doit demander l'accès à Gmail, pas à « tous les sites ».
  • Code source : s'il est open source, tout le monde peut vérifier ce qu'elle fait.
  • Qui la publie : des extensions sont parfois vendues, puis dégradées. Extension Guardian, un outil gratuit, montre qui publie n'importe quelle extension Chrome.

Ce qui ne marche pas

  • Un bloqueur de pub seul. Dans Gmail, les images viennent de l'adresse du proxy de Google, pas du traceur. La plupart des listes de filtres ne voient donc pas quelle image est un pixel espion.
  • Un VPN. Il cache votre adresse IP, ce que le proxy de Gmail fait déjà. L'ouverture est quand même enregistrée.

Questions fréquentes

Comment savoir si un e-mail contient un pixel espion ?

Avec Unseen, une petite note apparaît au-dessus de l'e-mail, avec le nom de l'entreprise de suivi. Sans extension, vous pouvez ouvrir l'e-mail, choisir « Afficher l'original » et chercher des images aux adresses longues et étranges, mais c'est fastidieux.

L'expéditeur saura-t-il que j'ai bloqué le pixel ?

Non. Il voit la même chose que pour quelqu'un qui lit ses e-mails avec les images désactivées : aucune ouverture enregistrée.

Est-ce que ça marche dans l'application Gmail sur téléphone ?

Non, Unseen fonctionne dans Gmail sur le web, dans le navigateur de l'ordinateur. Sur téléphone, utilisez le réglage « Images » décrit plus haut.

Et Outlook ou Apple Mail ?

Ce guide concerne Gmail. Apple Mail propose « Protéger l'activité Mail » dans ses réglages, et Outlook peut désactiver le téléchargement automatique des images.
