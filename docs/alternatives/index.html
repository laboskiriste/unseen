Gmail tracker blockers compared

Checked on November 2, 2026, from each Chrome Web Store page, GitHub and Firefox Add-ons. Written by the developer of Unseen, so read it with that in mind; we've tried to be fair, and corrections are welcome on GitHub.

All of these block the hidden images that tell a sender you opened their email. They differ in price, in how much of your browser they can access, and in whether you can check their code.

Trocker

A long-running, free and open-source blocker. It also handles click tracking for free, and it works in Outlook.com and Yahoo Mail as well as Gmail. The trade-off is access: to cover any webmail, it asks for access to all websites. Its own description explains why and says it makes no network requests. Pick Trocker if you use more than one webmail, or want free link cleaning.

PixelBlock

One of the oldest Gmail pixel blockers, with the most users here. It shows a red eye on tracked emails. It isn't open source, so you can't check what it does inside your Gmail. Its last update was in December 2025: what to do if you use PixelBlock.

Gblock

A paid, actively developed Gmail extension that blocks pixels and click tracking. It has a 30-day free trial, then a subscription. Pick Gblock if you want a commercial product with support and don't mind a monthly fee.

Ugly Email

A well-known open-source blocker that labels tracked emails with an eye. On November 2, 2026, its Chrome Web Store listing no longer loads, and the Firefox version was last updated in March 2024.

Unseen

Our extension. It blocks 330+ known trackers plus hidden and 1×1 images, shows which company tracked each email, and keeps every normal picture. What makes it different:

  • Access to Gmail only. No access to any other website, and no host permissions: blocking uses the browser's own rules.
  • Open source (MIT), and it makes no network requests of its own, except checking a Pro license key with the seller if you enter one.
  • Free forever for blocking. Pro (clean tracking links) is optional, with 30 days free, then $15 once, no subscription. If you want free link cleaning today, Trocker does that.

It's new, so it has few users and no reviews yet. Add Unseen to Chrome · Read the source · See it on AlternativeTo

Whatever you pick

A Gmail extension can see your email, so check who publishes it before you install, and again from time to time: extensions do get sold. Extension Guardian is a free checker that shows the publisher and warns you when it changes. Not sure you need an extension at all? Gmail's built-in setting works too, at the cost of hiding all pictures.
