Is this email tracking me?

Paste an email's original source and this page lists every tracking pixel in it: which company, and which server would learn that you opened it. It uses the same 330+ rules as the Unseen extension.

Runs entirely in your browser. Nothing you paste is uploaded or stored, and this page can't load any of the email's images.

1. Copy the email's original

  • Gmail: open the email, click ⋮ (top right of the message), then Show original, then Copy to clipboard.
  • Outlook.com: open the email, ⋯, View, View message source.
  • Apple Mail: View, Message, Raw Source.

2. Paste it here

What this can and can't see

  • It finds tracking pixels: images whose address matches a known tracker, and tiny or hidden images.
  • It doesn't flag tracked links. Most marketing emails also track clicks.
  • A tracker that isn't on the list and uses a normal-sized image won't show up. See the full list.
