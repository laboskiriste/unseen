PixelBlock alternatives for Gmail

Checked November 6, 2026. Written by the developer of Unseen, one of the options below.

PixelBlock is one of the oldest Gmail tracking-pixel blockers, with about 40,000 users in the Chrome Web Store. Its last update was in December 2025. That doesn't mean it stopped working, and you don't need to remove it today. But a Gmail extension that nobody updates has two problems:

  • Gmail changes. When Gmail's page changes, an unmaintained blocker can quietly stop catching trackers, and nothing tells you.
  • Unmaintained extensions get sold. A popular extension with access to your email is exactly what buyers look for. A new owner gets every permission, and Chrome installs their next update without asking you.

Check first: is it still the same publisher?

Paste PixelBlock's store link into Extension Guardian's free checker. It shows who publishes it today, when it was last updated and what it can access. If you keep it, the Extension Guardian extension can warn you if it's ever sold.

Trocker

Free, open source and long-running. It also cleans tracked links for free, and works in Outlook.com and Yahoo Mail too. The trade-off is that it asks for access to all websites. Pick Trocker if you use more than one webmail.

Unseen

Ours. It blocks 330+ known trackers plus hidden and 1×1 images, and shows a note above each tracked email naming the company, a bit like PixelBlock's red eye but with the name. It can only see Gmail, has no host permissions, and makes no network requests of its own. Blocking is free; an optional Pro feature cleans tracked links for $15 once. Add Unseen to Chrome

Gblock

A commercial, actively developed extension that blocks pixels and link tracking, with support. Pick Gblock if you prefer a paid product and don't mind a subscription.

No extension at all

Gmail's own setting, "Ask before displaying external images", stops pixel tracking without installing anything, at the cost of hiding every picture until you click. Step-by-step guide.
